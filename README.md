# Geschiedenis — Vellesan College

Showcase-site voor het vak Geschiedenis, gebouwd als alternatief voor Google Sites.

**Live:** https://jboersen88-dot.github.io/geschiedenis-vellesan/

Dit is een losstaand voorbeeld — nog niet gekoppeld aan meneerboersen.nl.

## Inhoud

Vier hoofdstukken, rechtstreeks gebaseerd op de eigen PowerPoints en doe-boeken van de docent:

1. **De Industriële Revolutie in Engeland**
2. **De Industriële Revolutie in Nederland**
3. **De sociale verhoudingen in Nederland**
4. **Welvaart voor iedereen** — met een zelftoets (`h4-oefentoets.html`)

## Techniek

Statische HTML/CSS/JS, geen build-stap, geen framework. Gehost via GitHub Pages direct vanaf de `main`-branch.

- Fonts: Fraunces (koppen) + Inter (body), via Google Fonts
- Scroll-reveal en hover-microinteracties volgens Emil Kowalski's animatieprincipes (transform/opacity, gated op `hover: hover`, `prefers-reduced-motion` overal gerespecteerd)
- Licht/donker thema volledig via CSS custom properties, geen JavaScript nodig voor theming
